# RFM transaction data

A dataset containing transactions of different customers.

## Usage

``` r
rfm_data_orders
```

## Format

A tibble with 49.6 rows and 3 variables:

- order_date:

  Order date.

- customer_id:

  Customer id

- revenue:

  Transaction amount.

- first_name:

  First name of the customer.

- last_name:

  Last name of the customer.

- email:

  email id of the customer.
